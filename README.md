# HTML Basics

A hands-on collection of HTML fundamentals, from first page to mini projects. Every file is commented so it reads like a learning journal.

## Contents

| Folder | What you learn |
|--------|----------------|
| 01-basic-structure | Doctype, head, body, meta tags |
| 02-text-and-links | Headings, paragraphs, links |
| 03-images-and-media | Images, audio, video |
| 04-lists-and-tables | Ordered, unordered lists, tables |
| 05-forms | Inputs, labels, buttons, validation |
| 06-semantic-html | header, nav, main, section, footer |
| 07-mini-projects | Profile, resume, landing and contact pages |

## How to run

1. Clone the repo or download it
2. Open any `index.html` in your browser
